# Project-T-5

Project Title: End-to-End Telco Customer Churn Prediction & Analytics
Overview:
This project is an end-to-end data analytics and machine learning solution designed to predict and analyze customer churn in the telecommunications sector. By processing raw Telco data, the project uncovers the key drivers of customer attrition—such as contract types, lack of tech support, and specific payment methods—and translates these findings into actionable business strategies to mitigate revenue loss.
Project Pipeline:
Data Preprocessing & Cleaning (Python):
Handled missing values, standardized categorical inconsistencies (e.g., city names), and engineered features to prepare a clean dataset ready for modeling.
Predictive Modeling (Machine Learning):
Developed and evaluated classification models (Logistic Regression and Random Forest) using scikit-learn to predict high-risk customers, achieving a robust accuracy rate (e.g., 80.2%).
Data Storytelling & Visualization (Power BI):
Designed a highly interactive, Dark Neon/Glassmorphism themed Power BI dashboard to present key metrics, including Churn Rate, Revenue at Risk, and Service-Level retention insights.
Actionable Recommendations:
Concluded the analysis with strategic, data-driven recommendations, targeting high-risk segments to improve customer retention and protect company revenue.
Tools & Technologies:
Python (Pandas, Scikit-learn, Matplotlib, Seaborn)
Power BI (DAX, Interactive Dashboards, UI/UX Design)
Machine Learning Classification Algorithms
